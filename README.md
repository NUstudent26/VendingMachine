# Vending Machine

A C++ vending machine program built in Visual Studio.

## Menu

Vending Machine
1. Show products
2. Select a product
3. Insert a coin
4. Swipe credit card
5. Purchase
6. Cancel transaction
7. [Operator] Restock a product
8. [Operator] Collect money
0. Exit

## Requirements

* Windows
* Visual Studio
* C++ Desktop Development workload

## Build and Run

1. Clone or download the repository.
2. Open `Vending.slnx` in Visual Studio.
3. Make sure the project is selected as the startup project.
4. Build the project with **Build → Build Solution**.
5. Run with **Ctrl + F5** or **Debug → Start Without Debugging**.
6. Use the menu to interact with the vending machine.
